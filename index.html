ค่าหลักของระบบ

กำหนดข้อมูลหลักที่จะแสดงในแอปและใช้ประกอบการจัดการข้อมูลรายวัน

จะแสดงเป็นตัวเลือกในรายการ
ไฟล์ JSON นี้ต้องมี `version` และ `url` ของ setup.exe เวอร์ชันล่าสุด
เวอร์ชันปัจจุบัน -
ยังไม่ได้ตั้งค่า URL อัปเดต

สิ่งที่ควรมีในระบบ

ส่วนนี้ช่วยให้ผู้ใช้งานเข้าใจว่าการตั้งค่าแต่ละค่าเอาไว้ทำอะไร และควรตั้งแบบไหนจึงจะเหมาะกับงานจริง

แนะนำให้ใส่ชื่อร้านแบบทางการ เพื่อใช้แสดงในส่วนหัวของโปรแกรมอย่างสม่ำเสมอ
ควรกำหนดยี่ห้อรถที่ใช้บ่อย เพื่อช่วยให้การแก้ข้อมูลหน้า list ทำได้เร็วขึ้น
หากไม่ต้องการให้ฐานข้อมูลโตเร็วเกินไป ควรกำหนดอายุการเก็บข้อมูลให้เหมาะกับรอบงานจริง
หลังเปลี่ยนค่า ควรทดสอบค้นหาและ export สักหนึ่งรอบเพื่อยืนยันว่าหน้าโปรแกรมยังแสดงผลตามต้องการ

ย้ายฐานข้อมูลจากเครื่องอื่น

ใช้เมื่อต้องการนำไฟล์ database.db จากคอมพิวเตอร์เครื่องเดิมมาใช้แทนฐานข้อมูลในเครื่องนี้ ระบบจะตรวจไฟล์ สำรองของเดิม และรีเฟรชรายการให้โดยอัตโนมัติ

1. เลือกไฟล์ เลือกไฟล์ .db / .sqlite จากเครื่องเดิม หรือจากแฟลชไดรฟ์
2. ตรวจและสำรอง ตรวจความถูกต้องของ SQLite และสำรองฐานข้อมูลปัจจุบันก่อนเสมอ
3. แทนที่อย่างปลอดภัย ปิดการเชื่อมต่อเดิม แทนที่ไฟล์ แล้วเปิดฐานข้อมูลใหม่ทันที
เหมาะสำหรับย้ายเครื่อง / กู้คืนจากไฟล์สำรอง
ปลอดภัยก่อนแทนที่: ระบบจะถามยืนยันและสร้างไฟล์สำรองฐานข้อมูลปัจจุบันก่อนนำเข้า
